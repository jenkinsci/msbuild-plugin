Note: The installation method described here only works on Windows.
Additionally, please note that only one major version, such as 2019, 2022 or 2026, reliably works on each system. Avoid using multiple instances of the same major version, such as 2022 and 2022.
Build Tools 2026 uses the 64-bit MSBuild, or the native Arm64 MSBuild on Arm64 agents. Older versions keep the 32-bit MSBuild.
