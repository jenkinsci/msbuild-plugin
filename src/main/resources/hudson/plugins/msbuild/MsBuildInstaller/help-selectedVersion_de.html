Hinweis: Die hier beschriebene Installationsmethode funktioniert nur unter Windows.
Zusätzlich beachten Sie bitte, dass nur eine Hauptversion, wie 2019, 2022 oder 2026, zuverlässig auf jedem System funktioniert. Vermeiden Sie die Verwendung mehrerer Instanzen derselben Hauptversion, wie beispielsweise 2022 und 2022.
Build Tools 2026 verwendet das 64-Bit-MSBuild, auf Arm64-Agents das native Arm64-MSBuild. Ältere Versionen behalten das 32-Bit-MSBuild.
